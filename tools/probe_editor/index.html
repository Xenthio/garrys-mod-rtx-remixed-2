Cubemap bounds

Hold right mouse and use WASD to fly; Q/E move down/up, Shift moves faster, and the wheel adjusts speed. Escape exits mouse look.

Drag yellow face handles to resize, the green square to move bounds (Alt when overlapping), or the blue capture point to move it independently. Use XYZ rotation fields or the optional orthographic views to rotate. Add cubemap places a volume at the camera.

Higher priorities win overlaps. Coordinates use BSP units. Capture points stay fixed when moving, resizing or rotating bounds.

Live save publishes edits when a runtime output is configured. The game keeps its previous valid reflections while changed captures are prepared.
